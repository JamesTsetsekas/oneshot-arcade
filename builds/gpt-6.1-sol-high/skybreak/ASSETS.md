# Asset provenance

All terrain, buildings, trees, floating rocks, copper wind machinery, skiff, wing-sail, scavengers, cache meshes, weapon shapes, map graphics, HUD, and effects are original procedural or hand-authored work created for this project. Source: `src/runtime.ts`, `src/main.tsx`, `src/style.css`, and `src/sim.ts`. License: MIT, granted by this project. No third-party images, fonts, models, maps, sound recordings, or music were used.

Sound effects are generated at runtime using Web Audio oscillators and gain envelopes. Source: `src/runtime.ts`. License: MIT.

System Arial/Helvetica/sans-serif fonts are used by name, not distributed. Unicode symbols are standard text glyphs supplied by the platform.

Runtime libraries: Babylon.js (@babylonjs/core, Apache-2.0); React and React DOM (MIT). Build/test tools: TypeScript (Apache-2.0), Vite (MIT), tsx (MIT), Playwright (Apache-2.0). Package versions are pinned by package-lock.json. Library code retains the upstream licenses distributed with the packages.
