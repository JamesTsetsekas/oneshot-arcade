# Assets and licenses

All environment geometry, map layout, procedural signs, SVG weapon silhouettes, characters, first-person rifle and hands, HUD, colors, particle shapes and oscillator audio were authored specifically for this slice. Original generated source/art: CC0-1.0. No downloaded models, textures, music, fonts, recordings or game assets are included. System Arial/Helvetica/monospace fonts are rendered by the user's OS and are not redistributed.

Runtime dependencies: Babylon.js core (Apache-2.0), React and React DOM (MIT). Tooling: Vite and Vitest (MIT), TypeScript (Apache-2.0), Playwright (Apache-2.0). Package licenses remain in their distributions; package-lock.json records resolved versions.
