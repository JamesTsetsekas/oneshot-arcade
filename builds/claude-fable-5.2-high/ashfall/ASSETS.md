# Asset manifest

Ashfall Covenant ships **no external art, audio, font, model, texture or level files**. Every asset is generated by
code in this repository at runtime, and was authored for this project.

| Asset | Source | License |
| --- | --- | --- |
| 3D models (heroes, 10 enemy families, bosses, NPCs, props, pickups, interactables) | Procedural primitives composed in `src/renderer-vfx/models.ts` and `src/renderer-vfx/dynamic.ts` | Original work for this project |
| Ground and wall textures | Painted to canvas at load in `src/renderer-vfx/renderer.ts` | Original work for this project |
| Particle sprite, telegraph decals, VFX | Generated in `src/renderer-vfx/dynamic.ts` | Original work for this project |
| Sound effects, ambience, adaptive drone music | Synthesized with Web Audio oscillators and filtered noise in `src/audio/audio.ts` | Original work for this project |
| Item icons | Inline SVG paths in `src/ui/widgets.tsx` | Original work for this project |
| Skill and UI glyphs | Unicode characters rendered with the user's system fonts (no font files shipped) | n/a |
| Level tiles, town map, item/affix/enemy/skill tables, names and text | Authored in `src/world-generation/tiles.ts`, `src/items/content.ts`, `src/navigation-ai/enemies.ts`, `src/abilities/skills.ts`, `src/progression/quests.ts` | Original work for this project |
| Favicon | Inline SVG data URI in `index.html` | Original work for this project |
