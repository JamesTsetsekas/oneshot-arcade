# Asset manifest

Shardfront ships **no external art, audio, fonts, maps or data files**. Everything the player sees or hears is
generated by code in this repository at load time or at runtime.

| Asset | Source | Licence |
| --- | --- | --- |
| Unit, structure, resource and neutral-object models (15 units, 12 structures, ore seam, vent, Watch Pylon, crystal barrier, salvage pod, sensor spike, cargo crystal) | Procedurally assembled from primitives in `src/render/models.ts` | Original work, created for this project |
| Terrain mesh, cliffs, bridges, rim peaks, brush, decorative crystals | Generated from the map definition in `src/world/map.ts` by `src/render/terrain.ts` | Original work |
| Glass Ravine map layout | Authored as code in `src/world/map.ts` | Original work |
| Portraits and command-card icons | Rendered at boot from the in-game models (`GameRenderer.renderIcons`) | Original work |
| Command glyphs, resource pips, favicon | Hand-written SVG paths / CSS in `src/ui/glyphs.tsx`, `src/ui/styles.css`, `index.html` | Original work |
| Visual effects (particles, projectiles, beams, decals, fog of war) | Shaders and geometry in `src/render/fx.ts`, `src/render/materials.ts` | Original work |
| Sound effects and adaptive music | Synthesised with the Web Audio API in `src/audio/audio.ts` (oscillators + filtered noise) | Original work |
| Balance data, unit and faction names, lore text | `src/data/defs.ts` | Original work |
| UI typeface | The player's system UI font stack (`Segoe UI`, `system-ui`, ...) - nothing is bundled | n/a |
