# Assets

Breachline ships **no binary art or audio assets**. Everything a player sees or hears is generated by code in this
repository at load time or at runtime, and is original to this project.

| Asset | Source | Where | License |
| --- | --- | --- | --- |
| Relay Station K-17 geometry, collision, spawns, nav | Hand-authored as data, meshed procedurally | `src/content/k17.ts`, `src/render/mapMesh.ts`, `src/sim/nav.ts` | Original work (this project) |
| Surface textures and normal maps (concrete, composite panels, metal, containers, wood, rock, grating, railing) | Drawn on canvases at load | `src/render/textures.ts` | Original work |
| Signage and decals (fictional names such as "Meridian Freight", "K-17 Stores") | Canvas text | `src/render/mapMesh.ts`, `src/render/textures.ts` | Original work |
| Sky, clouds, ocean | GLSL shader + generated normal map | `src/render/sky.ts` | Original work |
| Operator models for both factions | Procedural box/sphere rigs, GPU-instanced | `src/render/characters.ts` | Original work |
| All nine weapon models, attachments, arms | Procedural meshes from data | `src/render/weaponModels.ts`, `src/render/viewmodel.ts` | Original work |
| Equipment, devices, drone, strike aircraft, telegraphs | Procedural meshes | `src/render/entities.ts` | Original work |
| Particles, tracers, decals, muzzle flashes, obscurant cloud | Procedural sprites / thin instances | `src/render/vfx.ts` | Original work |
| Weapon reports, handling, impacts, footsteps, explosions, UI sounds, announcer stingers, warnings | Synthesized with the Web Audio API | `src/audio/audio.ts` | Original work |
| Menu and match music | Generated live by a step sequencer (Web Audio) | `src/audio/audio.ts` | Original work |
| HUD, menus, icons | HTML/CSS and Unicode glyphs | `src/ui/` | Original work |
| Fonts | Not bundled. CSS asks for fonts already installed on the player's system (`Bahnschrift`, `DIN Alternate`, `Roboto Condensed`, `Arial Narrow`, `Segoe UI`, system-ui) | `src/ui/styles.css` | n/a (system fonts, not redistributed) |
