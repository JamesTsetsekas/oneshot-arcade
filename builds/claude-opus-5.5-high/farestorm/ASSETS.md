# Assets and licenses

Farestorm ships **no external media files**. Every asset is generated by original code in this repository at
load time.

| Asset | Source | License |
| --- | --- | --- |
| Galeport city layout, roads, buildings, terrain, water, shortcuts, landmarks (`src/sim/world/*`, `src/render/cityMesh.ts`) | Original procedural/authored data written for this project | Same as this project (original work) |
| Cabs, traffic vehicles, passengers, pedestrians, props, pickups (`src/render/vehicles.ts`, `src/render/renderer.ts`) | Original code-built low-poly geometry with vertex colours | Original work |
| Textures: road markings, cobbles, facades/windows, sidewalks, ground noise, chevrons, particles, water normals, signs (`src/render/textures.ts`) | Painted at runtime on HTML canvas | Original work |
| Sky gradient shader (`src/render/renderer.ts`) | Original GLSL | Original work |
| Music, engine, tyre, wind, ambience, UI cues, passenger chirp voices (`src/audio/audio.ts`) | Synthesized live with the Web Audio API; original composition (chord loop, drum and bass patterns) | Original work |
| Passenger names, barks, destination and district names | Original writing | Original work |
| Favicon | Inline SVG in `index.html` | Original work |
| Fonts | None bundled; uses the system's installed fonts (Segoe UI / Arial Black / Impact fallbacks) | n/a |
