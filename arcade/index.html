HOW A RUN WORKS

A run starts in an empty workspace containing the brief and the . The model plans, builds, tests, screenshots, and writes an honest report on its own. Builds marked ITERATED predate the harness and had more than one attempt.

PLAY LOCALLY

Clone the repo, run npm run setup and npm start, then open 127.0.0.1:4160. Saves stay in your browser. No account is needed.

ADD A GAME OR MODEL

Add a brief to prompts/games/ or a model to catalog/models.json, then run npm run new-run. The README has the details.
